Each `.py` file is laid out the way it goes into the lab record:

1. **Aim**: the question, shortened to one comment line at the top
2. **Program**: the Python code

Handy when you need to write the record and the terminal is already closed.

## 🚀 Quick Start

```bash
cd ~/Programs/"DS LAB"

python3 15/15.py          # run experiment 15
cd 01 && python3 01.py    # run experiment 1 inside its folder, so 01.csv/.json/.xlsx land there
```

Programs that draw a graph pause at `plt.show()`. **Close the window to let the script finish.**
Experiment 37 opens in the web browser instead, and 38 opens two windows one after the other.

Just want the printed numbers, no windows:

```bash
MPLBACKEND=Agg python3 13/13.py
```

Experiment 5 has no random seed, so its numbers change on every run.

## ⚙️ Requirements

```bash
python3 -m pip install pandas numpy openpyxl scipy matplotlib seaborn scikit-learn plotly networkx nltk
```

Use **`python3 -m pip`**, not bare `pip`. On this machine `pip` points at a different Python, so
packages installed that way are invisible to `python3`.

Experiment 31 downloads its NLTK data (`punkt_tab`, `stopwords`) the first time it runs.

<details>
<summary>🕷️ Running in Spyder 6</summary>

<br>

Spyder ships its own Python environment, which lacks seaborn, scikit-learn, plotly, networkx and nltk.
Install them with Spyder's bundled conda:

```bash
~/Library/spyder-6/bin/conda install -p ~/Library/spyder-6/envs/spyder-runtime \
  -c conda-forge -y seaborn scikit-learn plotly networkx nltk
```

Set the working directory to the experiment's folder before running experiment 1.

</details>
